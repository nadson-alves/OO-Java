# OO-Java

Exercícios e estudos de Java com foco em **Programação Orientada a Objetos (POO)**.

## Conteúdos praticados

* Classes e objetos
* Construtores
* Encapsulamento
* Getters e setters
* Vetores
* Vetores de objetos
* Estruturas de repetição
* Estruturas condicionais
* Entrada e saída de dados

## Exercícios

O projeto reúne exercícios desenvolvidos durante meus estudos de Java, incluindo práticas com classes, objetos, vetores e lógica de programação.

## Objetivo

Este repositório faz parte da minha evolução nos estudos de Java e serve como registro prático do meu aprendizado em Programação Orientada a Objetos.
